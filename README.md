## 💫 About Me

I’m an engineer and developer with a background in **Automotive Engineering**, currently working as a **Model-Based Developer**.

I enjoy turning engineering problems into practical software and models—from simulation and validation to data-driven experimentation. My work brings together **mathematical modeling, software development, data analysis, and machine learning**.
